# Fitness Gamified Platform

Plataforma fitness gamificada para alunos, personal trainers, professores e academias.

## MVP

Cadastro de usuários, exercícios, fichas, execução de treinos, evolução, feedback de professores e gamificação básica.

## Stack planejada

- C# / ASP.NET Core
- Blazor WebAssembly PWA
- Entity Framework Core
- PostgreSQL
- ASP.NET Core Identity
- JWT + Refresh Tokens
- SignalR
- Docker
- Render.com
